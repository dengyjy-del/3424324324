# Раздел «Оценки»

Что изменилось в вашем боте и как этим пользоваться.

## Быстрый старт

1. `pip install -r requirements.txt`
2. В `.env` добавьте (остальное уже есть):

```
ADMIN_IDS=ваш_id           # уже используется режимом съёмки
RATE_ADMIN_ONLY=1          # 0 — открыть раздел всем
RATE_TERMS_URL=https://...
RATE_PRIVACY_URL=https://...
RATE_SUPPORT=@ascendlab_help
RATE_CONSENT_VERSION=2026-07-16
```
3. Положите фото в `seed_photos/` (см. README там же)
4. `python bot.py`

Раздел использует **тот же `DATABASE_URL`**, что и основной бот. На
Vercel это Postgres — отдельный SQLite там не пережил бы деплой.

## Что сделано

**Убрано:** раздел «Гайды» — таб и экран. Данные о покупках в базе
не тронуты, при желании раздел вернуть несложно.

**Добавлено:** вкладка «Оценки» рядом с «Разметкой». Обе видны только
тем, чей ID в `ADMIN_IDS` — используется существующий `session.is_admin`.

## Как это работает

**Онбординг.** Дисклеймер показывается один раз и записывается с
версией. Подняли `RATE_CONSENT_VERSION` — согласие спросят заново
у всех. Потом имя и возраст (18+, жёстко), потом фото.

**Оценка.** Пять кнопок: sub 3 / sub 5 / LTN / MTN / Chad. Тир
считается со сглаживанием и не показывается, пока оценок меньше пяти.

**Повторов нет.** Пара «зритель — анкета» пишется в `rate_seen` с
первичным ключом. Повтор физически невозможен — ни у живых анкет, ни
у демо, независимо от того, оценил человек, пропустил или пожаловался.

**Демо-анкеты** подмешиваются, когда живых меньше `RATE_MIN_LIVE_POOL`
(по умолчанию 5).

## Модерация

Кнопка «Пожаловаться» → карточка вам в личку (или в `MOD_CHAT_ID`)
с фото и снимком анкеты на момент жалобы. Четыре решения:

| Кнопка | Что происходит |
|---|---|
| Удалить анкету | Фото стирается, показы прекращаются, владелец уведомлён |
| Скрыть на 24ч | Анкета скрыта; **через сутки не возвращается сама** — нужно новое фото |
| Отклонить | Анкета остаётся в показе |
| Забанить | Доступ к разделу закрыт |

Жалоба на несовершеннолетнего прячет анкету немедленно, не дожидаясь
порога в три жалобы: цена ошибки здесь несимметричная.

Команды: `/rate_stats`, `/rate_reports`, `/rate_seed_reload`,
`/rate_unhide <id>`.

## Режим съёмки

Включите режим съёмки обычным кодом (`DEMO_CODE`), затем `/demo_card`.

Бот спросит фото → ник → оценку и соберёт сообщение вида
**«Алиса оценил(а) тебя на Chad»** с кнопками «Оценить» и «Написать».

Кнопки на карточке — реквизит: нажатие ничего не пишет в базу.
Каждая собранная карточка пишется в `rate_demo_log`, чтобы постановку
можно было отличить от настоящих оценок (`/rate_stats` показывает
счётчик).

Доступно только ID из `ADMIN_IDS` и только при включённом режиме съёмки.

**Про фото для карточек.** Ролик увидят посторонние, так что это
реклама. Фото должно быть вашим, стоковым с подходящей лицензией или
сгенерированным — чужое фото в промо подставляет и человека на нём,
и бота. Кнопка «Написать» показывает функцию, которой в боте нет;
если ролик обещает переписку, это претензия к рекламе, а не к коду.

## Файлы

```
mograte/
  core/       конфиг, хранилище, лента, модерация, фото, шкала
  tgbot/      роутеры бота, режим съёмки, доставка жалоб
  integration.py   подключение к вашему боту и мини-аппу
public/static/rate.v1.{js,css}   раздел внутри приложения
seed_photos/    демо-анкеты
```

Точки подключения: `bot.py` (`attach_rate`), `webapp/server.py`
(`mount_rate_api`). API раздела — `/api/faces/*`; префикс выбран так,
потому что `/api/rate` у вас уже занят.
