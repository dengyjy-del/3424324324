# Демо-анкеты

Фото отсюда подмешиваются в ленту, когда живых анкет мало. Каждая
попадается одному человеку не больше одного раза.

## Как добавить

**Просто:** назовите файл `Имя_Возраст.jpg` — например `Алина_23.jpg`.

**Правильно:** положите рядом `manifest.json` — там фиксируется,
откуда фото и на каком основании оно показывается:

```json
{"profiles": [
  {"file": "a1.jpg", "name": "Алина", "age": 23,
   "source": "Unsplash, фотограф X", "license": "Unsplash License"}
]}
```

Поля `source` и `license` не проверяются кодом — они нужны вам, когда
через полгода придётся вспоминать, откуда взялось конкретное фото.

## Что сюда класть нельзя

Фотографии реальных людей, которые не давали согласия на показ и
оценку. Это нарушает п. 4 и п. 5.5 ваших же Условий и ст. 152.1 ГК РФ.
Подходят: стоки с лицензией, разрешающей такое использование;
сгенерированные лица; ваши собственные фото.

Возраст меньше 18 — файл пропускается загрузчиком.

## Перезагрузка

Папка перечитывается при старте бота и командой `/rate_seed_reload`.
Удалённые файлы автоматически снимаются с показа.
