# Фотографии для наполнения режима оценок

Сюда кладутся снимки, которые показываются на оценку, пока живых анкет мало.

**Как добавить:** просто загрузи файлы в эту папку через GitHub —
`Add file` → `Upload files`. Ничего прописывать не нужно, приложение
подхватывает папку само.

Требования:

* формат `.jpg`, `.jpeg`, `.png` или `.webp`;
* только те фото, которые ты имеешь право показывать;
* людей младше 18 быть не должно — режим работает с 18 лет.

Одному пользователю каждый снимок покажется ровно один раз: оценённые
не возвращаются, как и живые анкеты.
